# KanaPrompt 仕様

内部識別子は`jp.kanaprompt.ime`、IMEサービスは`KanaPromptImeService`。製品名と内部名称はKanaPromptへ統一し、IME画面のバージョン番号表示は追加しません。

かなは指を離したときに即確定します。漢字変換・辞書・予測入力はありません。数字テンキー、英字QWERTY、数字記号・追加記号の画面を備えます。

- 通常削除は押下直後に1回、400ms後から65ms間隔で連続削除。選択範囲があればその範囲を削除し、それ以外はカーソル直前の1文字（結合絵文字を含む）を削除する。文字境界を取得できない場合は従来の1コードポイント削除に戻す。
- 左右カーソルキーは短押しで見た目の1文字（書記素クラスタ）分移動。400ms長押し後は65ms間隔で連続移動し、指を離すと止まる。
- 左全削除は350ms長押しで1回。カーソル左から先頭までを削除し、右側を残します。指を離す前にキーの外へ動かすと実行を中止します。範囲選択中や選択状態を取得できない場合は無操作。
- Shift1回は次の英字だけ大文字。続けて2回でロック、もう1回で解除。
- キー領域236dp（4段×59dp）、上8dp・下48dpの余白。
- フリック開始時は対象キー上の円形5方向ガイド。方向決定後は選択文字を32dpで表示。
- v1.0.6公開候補ではEXIF Marginと同じブランド山吹色 `#D99A22` を採用。アイコン背景も同色に変更し、アイコンの形は維持。システムのダークモードに連動し、設定画面は追加しません。
- 昼：背景`#FFFBF4`、文字キー`#FFFFFF`、補助キー`#FFE8B3`、文字`#29231B`、アクセント・押下面`#8A5900`、押下文字`#FFFFFF`、キー枠線`#796F60`。
- 夜：背景`#201D18`、文字キー`#39342D`、補助キー`#514532`、文字`#F7F0E7`、アクセント・押下面`#F5C76E`、押下文字`#29231B`、キー枠線`#B0A28C`。
- キーの輪郭は背景とのコントラスト3:1以上、文字・押下文字は4.5:1以上を満たす配色にする。従来のキー配列、高さ、余白、入力処理、5方向フリックプレビューは維持（配色のみ変更）。実機での表示・操作確認は未実施。

## 入力操作の参照基準

漢字変換を使わず、直接確定する単機能IMEのまま、**誤入力が起きにくい操作と挙動**を目指します。

- 主な参照先は **Gboard（Android・日本語12キー／英字QWERTY）**。ひらがなの各キーの中央・左・上・右・下への割当、フリックガイド、文字種切替、タッチ操作時の分かりやすさを比較します。
- **ATOK for Android** は濁点・半濁点・小文字の修飾、削除、カーソル操作を確認する補助資料とします。製品・バージョンや設定によって操作が異なるため、特定の方向割当まで同一とはみなしません。
- **変換・予測・辞書・学習・ユーザー別カスタマイズ・設定画面・操作感度の調整項目は追加しません。** 機能の数を増やさず、既存操作の正確さ・一貫性を改善します。
- 参照元をそのまま複製するものではありません。現行の独立した「かな／数字／QWERTY」切替、半角スペース、専用のカーソル／左全削除キー、濁点キーの直接フリックなどは維持し、操作変更は誤入力を減らす根拠と回帰検証がある場合に限ります。
- Gboardの「や」キー左右フリックによる括弧入力や、設定による3状態切替など、**現在は備えていない動作を準拠のためだけに追加しません。** 公式の説明は操作の参照資料であり、Gboard・ATOKの内部タッチ判定アルゴリズムや閾値を示す技術仕様ではありません。

入力の精度は、短い連続フリック、境界付近のタッチ、長文中のカーソル移動、絵文字を含む削除、別アプリの入力欄で確認します。具体的な数値や変更を決める前に、現行版と実機のGboard／ATOKの動きを比較し、不要な機能追加を避けます。

## 配列の根拠

かな句読点はGoogle公式のGboard解説、数字下段・US記号・テンキー寸法・フリックガイドはユーザーが表示したGboardの実機を観察して採用しました。Gboardの全設定・端末での完全一致は確認していません。数字1〜9への記号フリックは追加しない仕様です。

## 濁点・半濁点・小文字

- 「゛小」はタップで直前のかなを循環切替します（例：つ→っ→づ→つ、は→ば→ぱ→は）。
- 左フリックで濁点、右で半濁点、上で小文字へ直接切替。下は無操作です。
- つ・っの濁点は「づ」、は行の半濁点は「ぱぴぷぺぽ」、うの濁点は「ゔ」に対応します。すでに対象形の場合は変更しません。
- フリックガイドにはカーソル直前のかなに対応する候補だけを表示。選択範囲中、空欄、非対応文字では変更しません。確定時に入力欄の状態を再取得します。

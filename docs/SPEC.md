# KanaPrompt 仕様

かなは指を離したときに即確定します。漢字変換・辞書・予測入力はありません。数字テンキー、英字QWERTY、数字記号・追加記号の画面を備えます。

- 通常削除は押下直後に1回、400ms後から65ms間隔で連続削除。
- 左全削除は350ms長押しで1回。カーソル左から先頭までを削除し、右側を残します。範囲選択中は無操作。
- Shift1回は次の英字だけ大文字。続けて2回でロック、もう1回で解除。
- キー領域236dp（4段×59dp）、上8dp・下48dpの余白。
- フリック開始時は対象キー上の円形5方向ガイド。方向決定後は選択文字を32dpで表示。
- ミントの昼夜配色とKanaPromptのサイン。システムのダークモードに連動。

## 配列の根拠

かな句読点はGoogle公式のGboard解説、数字下段・US記号・テンキー寸法・フリックガイドはユーザーが表示したGboardの実機を観察して採用しました。Gboardの全設定・端末での完全一致は確認していません。数字1〜9への記号フリックは追加しない仕様です。

1.0.0では表示名とアイコンのみ変更し、完成確認済みv0.8.15の配列・操作を変更していません。

## v1.0.1 — フリックでの直接修飾（2026-10-26）

- ユーザー提供の2枚の画像を根拠に、゛小キーの左を濁点・右を半濁点へ割当。上は小文字への直接切替として追加（画像からGboardの上方向を確認したという意味ではない）。下は無操作。
- つ／っ→左でづ、は／ば→右でぱ。は行5文字、う→ゔ、対象かなの小文字に対応。すでに対象形ならそのまま。
- タップの従来の循環（つ→っ→づ→つ、は→ば→ぱ→は等）は維持。
- ガイドは入力先のカーソル直前の文字に応じ、実際の変換候補だけを表示。範囲選択中・空欄・非対応文字では候補なし、文字変更なし。確定時にも入力先を再読取。
- 即確定・変換なしの基本動作、署名とapplicationIdを維持。画像や私的入力内容はGit・ZIPに収録しない。

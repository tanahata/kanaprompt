# KanaPrompt（カナプロンプト）

**AIチャットへの日本語入力に特化した、漢字変換不要のフリックキーボード。**

AIチャットへ質問や指示を入力するとき、漢字の候補選択や変換の確定を減らし、考えをそのまま伝えることに集中したい。そのために、ひらがなを指を離した瞬間に確定するキーボードとして開発しました。従来の漢字変換IMEに置き換わることではなく、AIに話しかけるための、かな中心の入力方法を目指しています。

開発の経緯は、[開発者ブログ「AI入力用に変換機能のない日本語IMEを作った “KanaPrompt”」](https://tameha.net/android/kanaprompt/)でも紹介しています。

Android 10以降向け。無料・広告なし・MITライセンスです。

## ダウンロード

[最新版のAPKと更新履歴](https://github.com/tanahata/kanaprompt/releases/latest)

Releasesの `KanaPrompt-v1.0.1.apk` をダウンロードしてください。「Source code」はソースコードで、インストール用ではありません。

## 特徴

- かなをフリックして即確定。変換・辞書・予測入力はありません。
- かな／数字テンキー、英字QWERTY、数字と記号の2画面。
- 濁点・半濁点・小文字への切替。
- 長押しで連続削除、短い長押しでカーソルより左をまとめて削除。
- Shiftで英字1文字を大文字に、続けて2回押すと大文字ロック。
- 指元を避けたフリックガイドと、選択文字の拡大表示。
- ミント配色。スマホのダークモードに連動します。
- ネットワーク権限なし。入力文字の保存・送信、広告、解析SDKを実装していません。

## 導入

1. ReleasesからAPKをダウンロードしてインストールします。必要に応じて、利用したブラウザなどに「この提供元のアプリを許可」を設定します。
2. Androidの設定で「画面キーボード」または「キーボードを管理」を開き、KanaPromptを有効にします。名称や場所は端末により異なります。
3. 入力欄を開き、入力方法の切替からKanaPromptを選択します。

キーボードを有効にするとAndroidの標準的な注意画面が表示されます。本アプリのデータ取扱いは[プライバシー説明](PRIVACY.md)とソースで確認できます。

## 操作

| キー | 動作 |
|---|---|
| 1 / あ | かなと数字テンキーを切替 |
| a / あ | テンキーとQWERTYを切替 |
| ?123 / ABC / =\\< | QWERTYの英字・数字記号・追加記号を切替 |
| ゛小 | タップで循環。v1.0.1から左フリックで濁点、右で半濁点、上で小文字へ直接切替 |
| ⌫ | 1文字削除。長押しで連続削除 |
| 左側に山括弧の付いた⌫ | 約0.35秒押すと、カーソルより左を入力欄の先頭まで削除。範囲選択中は動作しません |

## 互換性と既知の制限

旧称はKana Flickです。正式名称の変更後も `applicationId` は `jp.kanaflick.ime`、入力メソッドのコンポーネントと署名証明書は既存版から維持しています。対応する旧版からは上書き更新できます。署名が異なる場合はアンインストールで回避せず、配布元を確認してください。

実機確認は主にAQUOS R9 proで行っています。すべての端末や入力先アプリを網羅したものではありません。TalkBackによるキーごとの操作など、アクセシビリティには未整備の部分があります。

Gboardを参考にした配列・表示がありますが、Googleと関係のある製品ではなく、全機能や寸法の完全互換を意味しません。根拠と独自仕様は[仕様](docs/SPEC.md)を参照してください。
